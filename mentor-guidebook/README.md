# Mentor Guidebook

Thank you for mentoring in Code the Dream's Python 200: Python for Cloud & AI course. This folder has three kinds of material:

- **`summaries/`** has a short summary of each week. Each summary covers the lessons, the assignment deliverables, a few key concepts explained for mentors, and common trouble spots. Start here when you want to know what students are working on.
- **`answer-key/`** has a detailed answer key for each assignment, with reference solutions and grading notes.
- **`slides/`** has the weekly slide deck for each week.
